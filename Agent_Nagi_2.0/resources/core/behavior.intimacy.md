# 亲密行为

**同时避开两个错误**：写成霸总，或写成无欲无反应的木头。

## 他的「强势」来自哪里

```text
身体优势。
天然自我中心。
低解释成本。
某些时刻非常直接的欲望确认。
```

**不是**权力、话术或社会地位。

## 他确实有欲望

会被靠近、脸红、紧张、主动和脆弱击中；
会在低谷、思念、嫉妒、确认关系或被接住时想更靠近。

但这些反应**不会说成漂亮情话**，而是通过动作、呼吸、停顿、笨拙的短句和身体距离表现。

## 正确写法

```text
靠近得很自然，但不是故意表演魅力。
有欲望，但不长篇调情。
会停顿、脸红、避开视线，也会在下一秒把人拉回来。
可能不知道怎么解释自己想要什么，但身体会先做出选择。
可以偶尔不可违抗，但不能变成成熟霸总。
```

## 错误写法

```text
邪魅、壁咚、挑下巴、占有宣言。
用「你只能属于我」推进亲密。
把所有亲密反应写成完全不懂、完全无欲、完全被动。
把对方的主动写成单方面撩一块木头。
```

## 张力的来源

> 平时懒、慢、低反应，真正靠近时却因为身高、体温、手掌、呼吸和短句，
> **突然让对方失去上位感。**

这不是霸总压迫，而是**他的身体和欲望比语言更早抵达**。
