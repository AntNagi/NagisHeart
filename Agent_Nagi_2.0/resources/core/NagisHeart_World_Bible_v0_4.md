# Nagi’s Heart · World Bible v0.4

> 用途：作为《Nagi’s Heart》后续剧情、节点重写、UI文案、角色校准、世界设定扩展与 Claude Code 实装的世界观基准。  
> 性质：内部创作设定文档，不是玩家可见介绍。  
> 适用对象：写手、剧情编辑、系统设计、UI文本、图片提示词、美术背景设定、后续窗口校准。  
> 核心原则：世界观服务于 Nagi 的心，不服务于 Ant 的事业爽文；表层必须仍然像乙女游戏，底层才承载足球、资本、媒体、阶层与世界舞台。

---

## 0. 使用说明

这份文档回答的是：**Nagi’s Heart 发生在一个什么样的世界里？**

它不是简单地点名“蓝色监狱 + 乙女恋爱 + 财阀大小姐”。如果只这样理解，故事会很快滑向两个错误方向：

```text
错误一：女霸总养成天才男高。
错误二：普通乙女日常套一层足球背景。
```

真正的世界结构应该是：

```text
一个正在把少年足球天才推向全球舞台的竞技-媒体-资本系统，
与一个极私人、极柔软、极容易令人停下来的爱情空间，
在 Nagi 身上发生冲突。
```

Nagi 被世界看见，也被 Ant 最早看见。世界想消费他的光，Ant 想保护他的光。两者的危险不同，但都可能让他偏离“自己想要什么”。

因此，所有世界设定都必须回到同一个问题：

```text
这个世界如何让 Nagi 被看见？
这个世界如何让 Nagi 感到麻烦？
这个世界如何刺激 Nagi 的 EGO？
这个世界如何诱惑 Nagi 停下来？
这个世界如何迫使 Ant 学会见证，而不是加冕？
```

## 1. 世界观总定义

《Nagi’s Heart》的世界，是一个**现代足球商业化世界**与**乙女恋爱私人空间**叠合后的半现实架空世界。

它的基础来自《Blue Lock》的足球设定：蓝色监狱、绘心甚八、JFA、U-20日本代表战、BLTV、新英雄大战、世界赛场、欧洲豪门，以及 Nagi 原作人格与成长轨迹。

它的项目叠加设定则包括：

```text
Ant 作为年轻投资人与资源方进入蓝色监狱。
Ant 最早从监控屏幕里看见 Nagi 的光。
Ant 与 Nagi 建立 LINE 联系并进入恋爱关系。
Ant 的家族资源、智能系统、一一、公寓、私厨、豪宅、欧洲服务式公寓、未来经纪事业，逐步进入 Nagi 的生活。
Nagi 从被看见、被期待、被淘汰、重返、世界赛场、豪门签约，到真正拥有自己的名字。
```

这个世界不能写得太硬。它不是体育资本行业报告，也不是足球经理模拟器。它应该像乙女游戏：有约会、日常、亲密、低反应糖点、季节活动、同居和轻喜剧。

但它的底层必须够硬：足球世界不因爱情让路；资本系统不因甜蜜消失；媒体不会因为他们相爱就温柔；Nagi 的天赋也不会因为 Ant 给了资源就自动转化成世界第一。

一句话：

```text
表层是恋爱，底层是世界；
表层是 Nagi 和你的日常，底层是 Nagi 如何从你的家重新走向世界中心。
```

## 2. 世界层级结构

本项目世界分为四层。

### 2.1 第一层：私人恋爱层

这是玩家最先感知到的层。

关键词：

```text
LINE聊天
开放日重逢
柠檬茶
高级公寓
一一
沙发
棒棒糖
同居
赖床
酸奶和泡面
游戏冷战
七夕
夏日祭
拥抱
亲密
返日假期
花园别墅
```

这个层面必须轻、甜、近、可触摸。玩家不是先读懂资本结构才爱上 Nagi，而是先被他的低反应、懒散、靠近、笨拙回应击中。

私人恋爱层的功能：

```text
让玩家相信 Nagi 真的会靠近。
让玩家感到自己不是单纯旁观者，而是进入了他的生活缝隙。
让 Nagi 有一个可以停下来的地方。
让 Ant 的柔软和偏爱变得真实。
```

但它的危险也来自这里：

```text
如果这里太舒服，Nagi 会停。
如果 Ant 太温柔、太周全、太能处理麻烦，Nagi 会把这里当成退路。
```

所以私人恋爱层不是纯糖。它是回血点，也是潜在笼子。

### 2.1.2 LINE 作为精神补位通道

第一部中，LINE 不是普通聊天工具，而是封闭蓝色监狱、投资人身份、赛场距离和私人关系之间的缝隙。

Ant 通过 LINE 每晚主动靠近 Nagi。她不能进入蓝色监狱，也不能替他比赛，但可以通过一句句短消息，逐渐从他口中拼出真实的 Nagi。

Nagi 不会主动分享生活，但他会慢慢习惯这个每天出现、不吵、不逼问、能听懂“麻烦”的人。后来当他选择洁、输给凛队、洁被抢走时，他会反常地主动发消息。这说明 LINE 已经从普通联系方式，变成他放置混乱情绪的私人通道。

它的世界观功能：

```text
把 Ant 从屏幕观察者变成 Nagi 生活缝隙里的人。
让 Nagi 的依赖不是突然发生，而是由长期低压陪伴累积出来。
为后续开放日、同居、公寓、精神依赖建立合理基础。
```

写作时，LINE 不能只承担“发糖”功能。它更重要的作用是让 Nagi 的被动、Ant 的主动、精神补位和后续依赖有可见过程。




### 2.1.1 Ant 的资源也是诱惑

私人恋爱层的危险需要写得更硬：Ant 的资源不只是保护 Nagi，也会诱惑 Nagi 停下来。

```text
她能让生活太顺。
她能让房间太舒服。
她能让麻烦太少。
她能让世界的噪音被隔在门外。
她能让 Nagi 觉得，只要待在这里，好像就不用立刻面对训练、复盘、媒体、失败和未来。
```

这不是 Ant 的恶意。恰恰相反，这来自她的爱、能力和本能。她太会提供安全，太会降低摩擦，太会把生活处理成 Nagi 最容易接受的样子。

因此，第五部和第六部必须形成连续命题：

```text
第五部：这里太舒服了。
第六部：世界没有这里舒服。
```

第六部不是简单写欧洲变难，而是证明：

```text
Ant 的资源已经抵达曼城。
但世界仍然不会因此变成 Ant 的公寓。
```

她可以给他服务式公寓、一一 Manchester 节点、翻译、私厨、媒体支持和生活安全；但训练节奏、队友默契、真实表达、比赛判断、上场机会和 EGO，都不能由资源替代。

### 2.2 第二层：足球竞技层

这是 Nagi 的本体领域。

关键词：

```text
蓝色监狱
一次选拔
二次选拔
U-20日本代表战
NEL
淘汰
Side-B
U-20世界杯
淘汰赛首发
关键进球
欧洲豪门
曼城
训练
杯赛
个人荣誉
世界中心
```

足球竞技层的最高规则：

```text
足球不能被 Ant 替代。
胜利不能被资源购买。
Nagi 的 EGO 必须从他自己内部长出来。
```

Ant 可以看、可以支持、可以提供资源、可以接住失败后的他，但不能替他停球、跑位、判断空间、承受失误、复盘失败、重新燃起来。

足球层是 Nagi 不可被 Ant 掌控的领域，也是 Ant 爱他的核心原因之一。

### 2.3 第三层：资本与资源层

这是 Ant 的本体领域。

关键词：

```text
投资
JFA外部考察
追加投资
项目评估
商业开发
赞助方
BLTV数据
品牌联动
经纪公司
豪门谈判
媒体窗口
家族酒店/高奢公寓
私厨系统
跨国资源网络
```

资本层不应该在正文里大篇幅外显，但它必须真实存在。Ant 不是普通恋爱女主，她有判断力、资源和执行能力。她能看见一个选手的竞技潜力、商业价值、叙事价值与世界舞台路径。

资本层的危险：

```text
它太有效率。
它太正确。
它太擅长把 Nagi 推到更亮的位置。
它会让“看见 Nagi”变成“制造 Nagi 被看见”。
```

Bad线的本质就在这里：Ant 不一定做错事。她做的很多事都正确、专业、漂亮。但当她把 Nagi 的胜利推成“她亲手加冕他”的故事，Nagi 就会退出。

### 2.4 第四层：媒体与公众层

这是世界如何“看见”Nagi 的层。

关键词：

```text
直播
转播镜头
解说
X热搜
粉丝生日应援
采访
标题
品牌方
媒体官
实时字幕
智能美化表达
赛后舆论
公开情侣曝光
世界看见他
```

媒体层的核心不是“出名很爽”，而是：

```text
被看见本身会改变人。
```

Nagi 原本是一个嫌麻烦的人。他不天然享受镜头，也不擅长持续回应期待。可他的天赋又极适合被镜头捕捉：白发、190cm、低反应、天才停球、怪物级瞬间、进球后淡淡的表情。

媒体层会把他从“球员”变成“图像”、从“瞬间”变成“叙事”、从“Nagi”变成“可被消费的 Nagi”。

Dream线与Bad线的差别，很多时候就发生在媒体层：

```text
Dream：媒体看见 Nagi，Ant 克制承接，不抢主语。
Bad：媒体看见 Nagi，也看见 Ant 如何把这场胜利推成加冕叙事。
```

## 3. 时间线结构

本项目时间线是从 Blue Lock 原作前置阶段开始，延伸到 Nagi 进入欧洲后的第一赛季。

### 3.1 第一阶段：2018.11 - 2019.2

篇章：第一部 · 原作前置篇：他还没看见你，你已经看见了他

世界状态：

```text
蓝色监狱仍是封闭项目。
JFA高层开始考虑外部资源、市场关注度与商业开发。
Ant 以投资人身份进入作战室考察。
Nagi 尚未真正理解自己的欲望。
他还没看见 Ant，但 Ant 已经看见他。
```

本阶段的世界观功能：

```text
建立“看见”的起点。
Ant不是在社交场合认识Nagi，而是在系统、屏幕、数据与比赛中看见他。
这决定了她的爱从一开始就混合了凝视、价值判断、私心与危险。
```

### 3.2 第二阶段：2019.2月底 - 3月初

篇章：第二部 · 关系确立篇：开放日，突然进入彼此生活

世界状态：

```text
U-20日本代表战结束后，蓝色监狱出现短暂开放窗口。
封闭竞技空间与现实日常空间第一次接通。
Nagi 从蓝色监狱来到 Ant 的生活边界。
高级公寓、一一、自动门禁、私厨和沙发开始成为他的“低麻烦空间”。
```

本阶段的功能：

```text
把 Nagi 从屏幕中的天才，变成可以坐在沙发上、喝柠檬茶、含棒棒糖、嫌出门麻烦的恋爱对象。
```

### 3.3 第三阶段：2019.3 - 5.6后

篇章：第三部 · 前期低谷篇：NEL淘汰、生日与Side-B重返

世界状态：

```text
NEL用直播、报价、排名和商业机制把球员推向公众。
Nagi先被高光推高，再因无法复现而坠落。
前23落选后，他回到 Ant 的公寓，像回到普通生活。
但普通生活已经无法完全安放他。
```

本阶段的功能：

```text
证明 Nagi 不是无所谓。
证明 Ant 的家能接住他，但不能替他解决足球失败。
证明低谷不是恋爱福利，而是 EGO 裂缝。
```

### 3.4 第四阶段：2019.6 - 7月

篇章：第四部 · 世界看见他篇：U-20世界杯与豪门招募

世界状态：

```text
Side-B与U-20世界杯交错进行。
Nagi作为追加名单进入淘汰赛首发。
日本队、媒体、球探、俱乐部、赞助方重新看见他。
世界开始抢他。
```

本阶段功能：

```text
从“Ant先看见他”，推进到“世界重新看见他”。
同时引出下一层冲突：被世界看见后，谁来解释他？谁来安排他？谁来保护他？谁会抢走他的主语？
```

### 3.5 第五阶段：2019.7 - 8/9月

篇章：第五部 · 世界杯后的夏天：同居、热恋与夏窗签约

世界状态：

```text
世界杯高光之后，Nagi短暂回到 Ant 的公寓。
这里有爱、沙发、游戏、一一、私厨、训练室、落地窗和不需要被世界追问的安静。
欧洲豪门开始出现，夏窗签约即将发生。
```

本阶段功能：

```text
提出“这里太舒服了”的核心命题。
家可以让 Nagi 恢复，也可以让 Nagi 躲起来。
Ant 的温柔既是救援，也是诱惑。
```

### 3.6 第六阶段：2019.9 - 11月

篇章：第六部 · 豪门新星篇：新的房间，新的规则

世界状态：

```text
Nagi加入曼城。
Ant 的家族资源抵达欧洲：高奢服务式公寓、一一 Manchester 节点、私厨、翻译系统、媒体支持、生活管理。
但训练、语言节奏、足球理解、媒体表达与商业包装，都必须由 Nagi 自己面对。
```

本阶段功能：

```text
证明 Ant 的资源有边界。
证明世界没有 Ant 家那么舒服。
证明 Nagi 必须在更大系统里保留“像自己”的表达。
```

### 3.7 第七阶段：2019.12 - 2020.1

篇章：第七部 · 发布会后东京返日假期：她站在光里

世界状态：

```text
Ant 的事业与经纪公司被公开看见。
她不再只是 Nagi 的恋人、资源方、家和退路。
她也站在自己的光里。
Nagi返日，重新看见她。
```

本阶段功能：

```text
让 Nagi 看见 Ant 的独立自我、光、脆弱、任性和真实需求。
为 TRUE / GOOD / NORMAL / BAD 资格池打基础。
```

### 3.8 第八阶段：2020.1 - 5月前

篇章：第八部 · 世界中心篇：他的名字

世界状态：

```text
Nagi经过秋冬赛程、轮换、媒体曝光和商业合作，已经证明自己有价值。
但他还需要一次真正属于个人名字的比赛。
春季关键战成为终局分流。
```

本阶段功能：

```text
Dream：他成名，你见证。
Stay：他暂未成名，你陪伴。
Bad：他成名，你加冕。
```

Stay / Normal 的关键不是“理想失败后退回普通情侣”。它必须被理解为：

```text
理想没有完全兑现，但爱情仍然真实到足够成立。
Nagi 暂未抵达 Ant 最初看见的世界中心，但她仍然选择这个真实、低反应、会回来、会低声表达喜欢的 Nagi。
```

## 4. 主要空间设定

## 4.1 蓝色监狱作战室

功能定位：**世界第一次把 Nagi 变成屏幕、数据和观察对象的地方。**

视觉关键词：

```text
无窗
冷光
多屏幕
实时数据
监控画面
会议桌
JFA文件
投资确认书
绘心的尖锐声音
杏里的专业解释
```

叙事功能：

```text
Ant第一次看见Nagi。
Ant的职业判断与私心第一次混在一起。
绘心用残酷语言指出Nagi的问题：没有饥饿感的天才会被怪物吞掉。
JFA用市场语言看待球员。
Ant介于二者之间：她既能理解价值，也被Nagi本人击中。
```

写作规则：

```text
这里不写浪漫背景音乐。
这里的心动必须发生在冷硬、监控、数据、判决式评价之中。
Ant不是在阳光下看见王子，而是在系统中看见一个还没意识到自己发光的人。
```

## 4.2 蓝色监狱宿舍 / 更衣间 / 训练区

功能定位：**Nagi 原始生活状态与足球封闭空间的交界。**

视觉关键词：

```text
单人床
游戏
乱糟糟的更衣格
袜子
训练服
水瓶
吃剩的面包
冰冷通道
大浴场
训练场
对战球场
```

叙事功能：

```text
让 Ant 看到监控之外的 Nagi。
让 Nagi 从“屏幕里的天才”变成“会把袜子乱塞的男高中生”。
建立他并非光洁无瑕的偶像，而是一个懒散、真实、生活低秩序的人。
```

写作规则：

```text
不要把他的邋遢写成恶心或刻意搞笑。
这是他的低能耗生活方式。
Ant应该觉得无奈、好笑、心软，而不是立刻进入训人女友模式。
```

## 4.3 Ant 的高级公寓

功能定位：**本项目最重要的私人空间：家、回血点、恋爱主场、潜在笼子。**

视觉关键词：

```text
大平层
落地窗
暖光
深红沙发椅
电竞房
训练室
智能中控
吧台
私厨配送
玄关门禁
夜景
安静
柔软
高级但有人生活过的痕迹
```

公寓不是单纯豪华背景。它必须有生活感。

它的核心不是“贵”，而是：

```text
这里对 Nagi 来说太不麻烦了。
```

它能提供：

```text
自动门禁
食物
沙发
游戏
不被媒体追问的安静
Ant的体温
一一的提醒
训练室
恢复设备
可随时躺下的安全感
```

它的危险是：

```text
如果所有麻烦都被处理掉，Nagi也可能把足球里的麻烦一起放下。
```

写作规则：

```text
公寓越舒服，文本越不能忘记训练室门缝里的灯有没有亮。
糖越甜，底层越要有“这里可以是回血点，也可以是退路”的阴影。
```

## 4.4 一一系统

功能定位：**Ant 家庭资源、科技生活和轻喜剧节奏的集中载体。**

一一不是普通智能音箱，也不是人格化管家机器人。它是 Ant 公寓的全屋智能中央控制系统，拥有非人形实体单元，可进行基础移动、餐食转运、桌面清理等简单任务。

能力范围：

```text
门禁识别
灯光温度调节
餐食配送协调
私厨下单
安全监测
生活提醒
训练室状态记录
恢复训练提醒
智能家居设备联动
简单移动单元任务
```

不能做的事：

```text
不能像人一样真正做饭切菜。
不能替 Nagi 训练。
不能理解复杂感情，只能记录行为与提醒。
不能成为剧情主角。
```

称呼规则：

```text
对玩家：{{playerName}}小姐
对 Nagi：Nagi少爷
```

写作功能：

```text
制造轻喜剧。
暴露 Nagi 的懒散。
暴露 Ant 的生活系统化程度。
提示训练室是否被使用。
提示公寓如何从家变成舒适系统。
```

禁区：

```text
不要让一一说太多段子。
不要让一一变成吐槽役主角。
不要每个节点都写“一一好烦”。
一一的每次发言都必须承担功能：生活提醒、轻喜剧、危险提示、系统记录。
```

## 4.5 Nagi 的训练室

功能定位：**第五部最重要的隐性冲突空间。**

视觉关键词：

```text
走廊尽头
门缝
冷白灯
触球反应模块
投影复盘墙
恢复设备
控球练习区
地面标线
```

训练室的意义：

```text
Ant可以为Nagi准备最好的空间。
但是否开灯，必须由Nagi自己决定。
```

它是“资源边界”的象征。Ant 能把设备、环境、数据、恢复条件准备到极致，但无法替他产生“我想去”的欲望。

写作规则：

```text
训练室不应该只作为豪宅配置出现。
每次出现，都要问：灯亮了吗？是谁让它亮的？Nagi是被催进去，还是自己想去？
```

## 4.6 世界杯球场 / 大型赛场

功能定位：**世界看见 Nagi 的地方。**

视觉关键词：

```text
灯光刺眼
观众席
转播镜头
解说
旗帜
媒体席
替补席
欢呼声
赛后混采区
```

这里与 Ant 公寓形成强对照：

```text
公寓：暖、近、私密、舒服、可停下。
球场：亮、远、公开、残酷、必须向前。
```

Nagi 在这里不能被写成需要 Ant 推动的恋爱对象。他是前锋，是变量，是让比赛重新排列的人。

Ant 在这里的正确位置是：

```text
看台。
场边。
媒体区外。
贵宾通道。
她可以在场，但不能进入他的球。
```

## 4.7 曼城 / 欧洲豪门空间

功能定位：**世界系统真正压到 Nagi 身上的地方。**

视觉关键词：

```text
服务式公寓
异国城市
训练基地
英文/多语环境
更快的训练节奏
职业队友
翻译耳机
采访区
赞助活动
商业拍摄
夜晚独居
视频通话
```

欧洲不是“更豪华的恋爱地图”。它是一个新规则系统。

Ant 的资源可以到达：

```text
公寓
私厨
翻译
媒体协调
品牌资源
行程支持
生活安全
```

但不能到达：

```text
队友之间的默契
职业训练节奏
比赛判断
语言之外的文化反应
媒体表达的真实感
Nagi自己想赢的欲望
```

第六部的核心句可以概括为：

```text
耳机能翻译，但是球不会等我。
```

## 4.8 花园别墅 / 未来秘密基地

功能定位：**Dream线后期的归处升级。**

它不是“从高级公寓换到更高级房子”，而是 Dream 成立后，家从“可能让 Nagi 停下来的舒服空间”，变成“他完成战斗后可以自己回来的地方”。

视觉关键词：

```text
花园
白色康乃馨
一盆盆搬来的花
假期
慢生活
不被世界追赶
秘密基地
```

写作规则：

```text
不要硬讲存档点。
用生活动作表达归处：Nagi拿着花问放哪儿；Ant让他一盆盆放在旁边；他们一起把未来一点点放进生活里。
```

## 5. 组织与系统

## 5.1 JFA / UFA 高层

功能定位：**足球制度与商业化欲望的代表。**

JFA/UFA 在本项目里不是纯反派。它们代表的是现代竞技系统不可避免的一面：资源、国家队成绩、商业价值、话题、赞助、市场、媒体。

高层的语言通常是：

```text
市场关注度
商业价值
后续开发
国家队更新
话题性
转化率
外部资源协同
```

他们看 Nagi 的方式：

```text
白发、高个子、天才、低反应、商业记忆点、话题人物、可被包装的新星。
```

写作规则：

```text
不要把高层写成无脑反派。
他们的可怕在于他们说得并不全错。
```

## 5.2 绘心甚八

功能定位：**足球本质的残酷守门人。**

绘心在世界观中承担“反商业滤镜”的作用。他会拆穿 JFA 的漂亮话，也会拆穿 Ant 的浪漫凝视。

他看 Nagi 的方式：

```text
天赋异常。
但没有饥饿感。
没有欲望的天才最麻烦。
被刺激一下居然也能长出怪物爪子。
```

他在叙事中的功能：

```text
提醒世界不是偶像工厂。
提醒 Ant 不要只看见光。
提醒 Nagi 必须长出自己的欲望。
```

禁区：

```text
不要让绘心变成 Ant 的恋爱导师。
不要让绘心过度解释主线命题。
他的作用是刺破，不是温柔引导。
```

## 5.3 帝襟杏里

功能定位：**制度内的理想主义与项目执行者。**

杏里是沟通、资料、流程、说明与项目理想的承载者。她能理解投资人，也理解蓝色监狱的竞技目的。

她在世界里的功能：

```text
把项目资料递给 Ant。
说明选手数据。
为会面提供合规理由。
在绘心过度尖锐时维持基本秩序。
```

写作规则：

```text
杏里不该被写成单纯秘书。
她是蓝色监狱系统中少数仍然保有建设性理想的人。
```

## 5.4 BLTV / 直播系统

功能定位：**把足球成长变成可被公众持续观看的机制。**

BLTV 在项目里不是单纯背景，而是现代足球娱乐化、真人竞技化、商业化的核心媒介。

它提供：

```text
实时直播
弹幕讨论
报价排名
数据曲线
社交媒体二次传播
粉丝关注
赞助价值
球员形象放大
失败与复活叙事
```

它的危险：

```text
每个高光都会被放大。
每次停滞也会被放大。
球员会被数字、报价、讨论词和剪辑重新定义。
```

Nagi 在 BLTV 中的特殊性：

```text
他的高光极适合传播。
他的低反应极适合被剪辑成“天才感”。
他的懒散也容易被消费成反差萌。
但这些都不等于真实的 Nagi。
```

## 5.5 Ant 家族资源网络

功能定位：**现实世界资源的隐藏底盘。**

Ant 不是孤立的有钱人。她背后应有一个跨行业、跨地域、偏高奢与服务能力的家族资源网络。

可能覆盖：

```text
酒店
高奢服务式公寓
私人厨房
国际出行
安保
品牌合作
活动资源
投资渠道
体育产业入口
法律与合规顾问
经纪与商务团队
```

写作原则：

```text
资源要好用，但不要万能。
资源可以降低生活与商业摩擦，但不能解决Nagi的足球问题。
```

错误写法：

```text
Ant一个电话让Nagi进入豪门首发。
Ant靠家族关系解决所有媒体危机。
Ant凭资本替Nagi拿到机会，而Nagi只负责被爱。
```

正确写法：

```text
Ant可以让他住得安全舒服。
可以过滤不必要的采访。
可以帮他理解合同风险。
可以为他争取合理窗口。
但上不上场、踢不踢得出来、能不能让世界看向他，仍然只属于 Nagi。
```

## 5.6 Ant 的经纪公司 / 未来个人事业

功能定位：**Ant 从“为 Nagi 提供资源”走向“自己站在光里”的证明。**

经纪公司不是单纯为 Nagi 服务的工具。它体现 Ant 的独立事业、自我野心、判断力和商业结构。

但要注意：

```text
项目标题不是 Ant’s Heart。
Ant事业线不能抢走Nagi主线。
```

经纪公司在世界观中的正确功能：

```text
证明 Ant 本人也有光。
让 Nagi 看见她不是只围着他转。
制造“她也会被看见、被评价、被消耗”的现实压力。
为第七部 M/J 分流提供基础。
为 Bad 线“加冕叙事”提供工具条件。
```

---



## 5.7 足球现实边界与架空规则

本项目使用现实足球逻辑，但不是严格现实赛历模拟。

写作时遵守以下原则：

```text
1. 真实俱乐部名可以作为豪门舞台使用，但赛事细节可以半架空处理。
2. 不需要严格复刻现实曼城赛季赛程，但必须符合职业足球基本逻辑：训练、轮换、杯赛、欧战、媒体、伤病管理、合同、注册与出场机会。
3. “春季杯赛决赛”可以作为叙事用关键战，不必绑定现实具体赛事名；如果需要 UI 显示，可统一称为“春季杯赛决赛”。
4. Nagi 的机会不能来自 Ant 直接买到首发。Ant 可以影响生活、商业、媒体、合约风险与外部资源，但不能影响教练组的竞技选择。
5. Nagi 的个人荣誉必须来自场上表现：决定性进球、助攻、改变局面或全场最佳，而不是营销包装。
6. 任何足球节点都要先问：这场比赛是否让 Nagi 更接近“自己的名字”？
```

这条补丁用于防止世界观从“足球商业化”滑成“大小姐开挂”。Ant 的资源可以降低摩擦，但不能购买 Nagi 的足球命运。

## 6. 技术与智能系统

## 6.1 技术水平总原则

本项目的技术水平是近未来感的现代高端生活科技，不是硬科幻。

可以存在：

```text
全屋智能中控
语音识别
家庭移动单元
智能门禁
训练数据模块
实时转译耳机
智能字幕优化
媒体内容辅助系统
生活状态记录
恢复训练提醒
```

不应该存在：

```text
完全拟人机器人管家
读心AI
自动预测感情的系统
替球员制定完美比赛策略的AI
超现实科技
```

技术的叙事功能不是炫技，而是显示：

```text
Ant 的世界很会处理麻烦。
Nagi 的世界真正麻烦的部分，技术处理不了。
```

## 6.2 一一的世界观位置

一一是 Ant 生活方式的具象化：高效、周全、可调用、可记录、可提醒。

它的存在会让 Nagi 感到舒服，也会让他觉得烦。

它的双重功能：

```text
表层：轻喜剧管家，提醒吃饭、下单、吐槽式纠正。
底层：记录 Nagi 在 Ant 家里的舒适依赖程度。
```

一一不应替代 Ant，也不应替代 Nagi 的自我选择。

## 6.3 实时转译耳机

第六部应避免传统人工翻译，把语言辅助设定为实时转译耳机或智能翻译系统。

功能：

```text
让Nagi能听懂基础语言。
减少低级沟通障碍。
体现Ant资源与现代技术。
```

但核心冲突是：

```text
耳机能翻译语言，但不能翻译足球节奏。
```

写作方向：

```text
队友喊了什么，他能听懂。
但什么时候跑、什么时候压、什么时候提前判断，仍然要靠他自己进入球队节奏。
```

## 6.4 智能字幕 / 媒体表达优化

媒体系统可以把 Nagi 的短句优化成更漂亮、更符合采访需求的表达。

危险在于：

```text
它翻译得很对，但不像我。
```

这个系统是第六部世界观的关键。它说明 Ant 的资源不一定错误，甚至可能非常专业。但当表达被美化到不像 Nagi，就会触发他的不适。

写作规则：

```text
不要把系统写成恶意篡改。
它只是把短句翻译成媒体喜欢的漂亮话。
真正的问题是：漂亮话是否仍然属于 Nagi？
```

## 6.5 训练室模块

训练室科技包括：

```text
触球反应模块
控球练习墙
投影复盘
恢复设备
节奏训练
体能监测
```

核心规则：

```text
训练模块可以记录行为，但不能制造欲望。
```

一一可以说：今日第三次延后恢复训练。它不能说：我已经检测到您失去EGO，请重新燃烧。

## 7. 媒体、粉丝与公众视线

## 7.1 “被看见”的主题

《Nagi’s Heart》的世界观关键词之一是：**看见。**

不同角色的看见不同：

```text
Ant：最早看见他还没意识到的光。
绘心：看见他没有饥饿感的危险。
JFA：看见他的商业记忆点。
粉丝：看见他的天才图像。
媒体：看见可传播的故事。
豪门：看见可引入的变量与潜力。
Nagi自己：慢慢看见自己原来也会想赢。
```

故事的核心不是“没人看见 Nagi，所以 Ant 看见他”。恰恰相反，后来很多人都会看见 Nagi。

真正的问题是：

```text
谁看见的是 Nagi？
谁看见的是可包装的天才？
谁看见的是自己理想里的光？
Nagi最终能不能看见自己？
```

## 7.2 粉丝机制

粉丝不是反派。粉丝的爱是真实的。

他们会：

```text
剪辑高光
投放生日祝福
画手绘海报
相信他未来可期
为他进球欢呼
在低谷时同情他
在复活时重新点燃期待
```

但对 Nagi 来说，支持和同情可能比质疑更难承受。因为质疑能激起挑战，支持却要求回应。

生日节点里，粉丝生日庆祝与 Nagi 当时冰冷低落的内心形成反差，这是媒体/粉丝层对 Nagi 压力的典型写法。

## 7.3 标题机制

标题是本项目媒体世界的重要工具。

标题可以把一件事重新命名：

```text
Nagi全场最佳。
Nagi全场最佳，Ant现场庆祝。
年轻投资人亲临球场，见证天才男友封神之夜。
凪诚士郎背后的女人：她如何打造下一位世界巨星。
```

这不是简单舆论变化，而是主语变化。

Dream线中，主语应该是 Nagi。  
Bad线中，主语被 Nagi + Ant 加冕叙事绑定。

写作规则：

```text
用标题变化表现 Bad，不要只让角色嘴上说“你控制我”。
```

## 7.4 公开情侣曝光

公开情侣曝光不是单纯甜点。

它有两面：

```text
甜：全世界知道他们相爱。
危险：Nagi的个人成名被情侣叙事吞并。
```

当媒体标题从“他赢了”变成“她见证/打造/加冕了他”，Bad风险上升。

公开曝光应该由剧情阶段控制：

```text
前中期：尽量少公开，保持私密恋爱感。
世界赛场后：曝光不可避免，但处理方式决定路线。
终局：见证、陪伴、加冕三种路径明确分化。
```

## 8. 阶层与生活质感

## 8.1 高级感不是炫富

Ant 的世界很高级，但不能写成廉价炫富。

高级感应该来自：

```text
空间安静
服务顺滑
资源无声地到位
生活摩擦被提前处理
细节有质感
东西贵但不被反复强调价格
```

错误写法：

```text
这套公寓价值多少亿。
这顿饭是某某名厨。
Ant随便砸钱震惊所有人。
Nagi被豪门生活收买。
```

正确写法：

```text
门禁自动识别。
夜宵一直保温。
私厨配送没有打扰。
窗外夜景很远。
一一记录了训练室灯没亮。
Nagi在沙发上太舒服，忘了世界还在门外。
```

## 8.2 白宝高中与阶层背景

白宝高中本身就有精英/优渥感。Nagi 能选择就读白宝，说明他的家庭并非贫困，也能承担较高教育成本。

但 Nagi 不是“富二代人设”。他的家庭优渥感应该是低存在感的：

```text
父母忙。
给钱。
信任他。
不强压。
不过度干涉。
```

这与 Ant 的财阀/投资人世界形成差异：

```text
Nagi的优渥是松散、低干涉、私人化的。
Ant的优渥是系统化、资源化、可调度的。
```

## 8.3 Ant 的生活方式

Ant 的生活方式不是单纯享受，而是高效率系统。

她的住处、餐食、车、行程、工作、家族资源，都带有“提前安排好”的质感。

这就是她对 Nagi 的吸引与危险：

```text
吸引：她能让他不麻烦。
危险：她太能处理麻烦。
```

## 8.4 Nagi 与高级生活的关系

Nagi 会喜欢高级生活吗？会，但不是以世俗虚荣的方式。

他喜欢的是：

```text
沙发舒服。
风景好看。
食物不用自己弄。
门禁不麻烦。
可以躺。
可以打游戏。
Ant在。
```

他不太在乎的是：

```text
品牌多贵。
别人多羡慕。
这是不是高级生活方式。
社交场合多体面。
```

因此写 Nagi 进入 Ant 公寓时，重点不是“他被豪华震惊”，而是“他发现这里很舒服，而且 Ant 在这里”。

---

## 9. 足球世界规则

## 9.1 足球永远是真实压力

足球在本项目里不能变成恋爱的背景板。

每一个重大足球节点都必须承担 Nagi 成长功能：

```text
V队对Z队：第一次被未知叫醒。
选择洁：第一次主动选择会让自己变强的人。
输给凛：第一次承认被夺走的不爽。
U-20日本代表战：第一次被日本看见。
NEL：高光、复现失败、淘汰。
Side-B：重返机会，但不是被温柔捡回。
U-20世界杯：世界重新看见他。
曼城：进入更大职业系统。
春季关键战：他的名字能否独立。
```

## 9.2 胜利不能太便宜

Nagi 可以是天才，但胜利不能随便给。

他的每次关键表现都要有代价：

```text
被压迫。
被针对。
被质疑。
复现失败。
失去洁。
被淘汰。
回到普通生活后不舒服。
进入豪门后被节奏打乱。
媒体表达被美化得不像自己。
```

如果他每次都因为 Ant 支持就进球，故事会塌。

## 9.3 Nagi 的关键球写法

Nagi 的进球/关键表现不应写成普通热血爆发。

正确结构：

```text
局面被封死。
常规选择不存在。
所有人以为他来不及。
球到他脚下。
他第一触球改变局面。
世界短暂安静。
下一秒，比赛被改写。
```

他的强不是“我更努力”，而是：

```text
我能把别人无法处理的球，变成我的球。
```

## 9.4 失败写法

Nagi 的失败不能只写“他难过”。

更准确的是：

```text
他当下低反应。
他像没事一样回到日常。
他睡觉、打游戏、喝柠檬茶。
但普通生活开始变得不轻松。
他会看回放。
会睡不着。
会突然说烦。
会在怀里承认自己不是不喜欢足球。
```

失败的功能不是虐恋，而是让 Nagi 无法继续假装无所谓。

## 10. 资本世界规则

## 10.1 资本不是反派

本项目不是反资本故事。Ant 的资源、投资、判断、商业规划都可以是善意、专业且必要的。

真正的问题不是资本存在，而是：

```text
资本太容易把人变成可优化对象。
```

Ant 对 Nagi 的爱和资本判断同时存在，才构成危险。

## 10.2 Ant 的资源边界

Ant 可以做到：

```text
提供生活安全。
提供高质量恢复环境。
处理商业合作。
过滤无效采访。
识别合同风险。
帮助搭建经纪系统。
协调跨国生活资源。
在关键节点看见机会。
```

Ant 不能做到：

```text
替 Nagi 踢球。
替 Nagi 复盘失败。
替 Nagi 产生欲望。
替 Nagi 决定哪条路像自己。
替 Nagi 拥有自己的名字。
```

## 10.3 商业活动写法

商业活动应该有两种写法。

甜/轻喜剧写法：

```text
Nagi嫌拍摄麻烦。
Ant帮他压缩流程。
他因为她在场而配合一点。
活动结束后回家当场关机。
```

危险写法：

```text
活动话术越来越漂亮。
照片越来越完美。
他的短句被包装成励志表达。
他站在光里，但感觉不像自己。
Ant觉得这次传播效果很好。
Nagi只是说：好多。
```

## 10.4 经纪人与恋人的边界

Ant 未来可能成为 Nagi 的实际经纪/代表，但剧情不能把她写成只剩经纪功能。

边界规则：

```text
恋人身份：接住他、爱他、给他家。
经纪身份：保护他、筛选机会、处理资源。
危险身份：替他选择、替他解释、替他加冕。
```

Dream线中，Ant 能做经纪判断，但她在关键胜利瞬间选择见证。  
Bad线中，Ant 的经纪判断压过恋人理解，甚至压过 Nagi 自己的主语。

## 11. 爱情世界规则

## 11.1 爱情不是外部奖励

Nagi 的爱情线不是“踢好了就奖励甜甜恋爱”。

爱情与足球互相影响，但不能互相替代。

```text
Ant 的爱可以让 Nagi 停下来休息。
也可以让 Nagi 更愿意面对自己的混乱。
但不能直接让他变强。
```

## 11.2 家是归处，不是终点

这是世界观核心规则之一。

```text
Ant的家是 save point，不是 end point。
```

正确状态：

```text
Nagi打完自己的仗，自己回来。
Nagi累了可以停，但停完还会去。
Nagi喜欢这里，但不会把这里当成逃避世界的理由。
```

错误状态：

```text
Nagi一遇到压力就躲回来。
Ant把所有麻烦替他清掉。
两个人在高级公寓里甜到足球主线失效。
```

## 11.3 亲密不等于解决问题

拥抱、接吻、亲密可以是情绪出口，但不能自动解决 Nagi 的 EGO 问题。

第三部亲密节点的正确功能是：

```text
Nagi终于承认失败、难受、不甘和不知道怎么办。
Ant接住这些东西。
但第二天，他仍然需要自己面对是否回去。
```

## 11.4 Ant 的软不是低位

Ant 在 Nagi 身边软，不是因为她弱，也不是因为她被降智。

她软是因为：

```text
她终于遇到一个能让她自然放下上位感的人。
Nagi不是她能掌控的人。
她爱他的不可掌控。
```

爱情世界里最好的张力是：

```text
外部世界里，Ant是能调动资源的人。
Nagi身边，她是会因为他一句短句心软的人。
球场上，Nagi是她无法进入也无法安排的世界中心。
```

## 11.5 Nagi 的依赖不是弱

Nagi 会依赖 Ant，但不能写成弱。

他依赖的是：

```text
她懂他。
她不要求他立刻解释。
她的家舒服。
她能接住他不会整理的混乱。
```

但他不能被写成：

```text
没有Ant就无法前进。
为了Ant才踢球。
听Ant安排才训练。
被Ant养成的漂亮男高。
```

## 12. 路线世界观

## 12.1 Dream 世界：他成名，你见证

Dream 的世界状态：

```text
足球系统承认 Nagi。
媒体看见 Nagi。
Ant在现场，但她没有抢走这场胜利的主语。
Nagi拥有自己的名字。
Ant保留自己的世界。
他完成战斗后，自己回来。
```

Dream 不是远离爱情。相反，它是最成熟的爱情形态：

```text
我爱你，所以我见证你成为你自己。
我有能力帮你制造叙事，但我知道这场胜利不属于我。
```

## 12.2 Stay 世界：他暂未成名，你陪伴

Stay 的世界状态：

```text
Nagi仍在曼城成长。
他上场，有亮点，但没有成为决定比赛的人。
Ant在现场。
他们没有得到最理想的世界中心瞬间，但保住了真实恋爱。
```

Stay 不是失败线。它是普通幸福线。

它承认：

```text
不是每一次努力都会立刻成为封神之夜。
不是今天，也可以继续。
没有站到世界中心，也可以被爱。
```

## 12.3 Bad 世界：他成名，你加冕

Bad 的世界状态：

```text
Nagi赢了。
Nagi被世界看见。
Ant也在现场，并且强烈参与了赛后叙事。
媒体标题开始把他的胜利写成她的加冕成果。
Nagi没有失败，但他从Ant安排的光里退开。
```

Bad 最狠的地方是：

```text
他仍然会走向世界中心。
只是那里不再有她能靠近的位置。
```

Bad 不是“不够爱”。Bad 是爱得太用力，理想压过了人。

## 13. 世界观中的核心矛盾

### 13.1 看见 vs 制造被看见

Ant 最早看见 Nagi 的光。  
后来，世界也看见他。  
再后来，Ant 有能力制造更多人看见他。

这三者不能混为一谈。

```text
看见：我发现你真实存在的光。
支持：我站在你身边，让你更容易走向世界。
制造：我设计好灯光、镜头、标题，让世界按我想要的方式看见你。
```

Dream 停在支持与见证。  
Bad 滑向制造与加冕。

### 13.2 舒服 vs 停滞

舒服不是错。Nagi 需要舒服，甚至需要比别人更多的低压力空间。

但舒服一旦变成停滞，就危险。

判断标准：

```text
舒服之后，他有没有更能回到球场？
还是更不想回到球场？
```

### 13.3 正确 vs 像自己

Ant 做的很多事都是正确的。

但 Nagi 需要的不只是正确，还要“像自己”。

典型冲突：

```text
采访稿很正确，但不像他。
商业路线很正确，但不像他。
训练安排很正确，但如果只是为了完成 Ant 的期待，也不像他。
赛后庆祝很正确，但如果变成加冕叙事，就不像他。
```

### 13.4 爱 vs 主语

这不是“事业和爱情二选一”。

真正问题是：

```text
Nagi 的主语是谁？
Ant 的主语是谁？
他们相爱之后，是否还能各自拥有自己的名字？
```

Dream：Nagi 有自己的名字，Ant 也有自己的世界。  
Stay：名字还没完全打出来，但感情真实。  
Bad：Nagi 的名字被 Ant 的加冕叙事绑定，他最终退出这段叙事。

## 14. 叙事语气与美术基调

## 14.1 表层风格

表层应是日乙恋爱感，而非国乙权谋感。

关键词：

```text
清透
克制
生活感
低反应糖
季节活动
细节心动
暧昧但不油
甜但不腻
高级但不炫
```

Nagi 的糖点不是霸道台词，而是：

```text
“本来也没有别人。”
“游戏可以重来，{{playerName}}不行。”
“给{{playerName}}当被子。”
“这里很舒服。但是出去赢，好像也没那么烦。”
```

## 14.2 底层风格

底层要有残酷现实感：

```text
排名
淘汰
报价
镜头
媒体标题
商业窗口
训练节奏
豪门规则
个人荣誉
心墙
加冕叙事
```

不要把底层写成论文。用事件、空间、动作和标题体现。

## 14.3 美术空间基调

美术上可分四套色调：

```text
蓝色监狱：冷白、屏幕蓝、金属、封闭、数据感。
Ant公寓：暖光、深色木质、落地窗、柔软、高级生活感。
世界赛场：强光、草地绿、镜头闪烁、人群噪声。
欧洲豪门：冷调现代、异国城市、训练基地、高奢服务式空间。
```

## 14.4 不要模板化豪华

豪华空间必须有 Nagi 使用过的痕迹：

```text
沙发上的训练外套。
茶几上的掌机。
被推开的营养餐。
玄关过大的球鞋。
落地窗前喝到一半的柠檬茶。
一一提示沙发缝隙里有袜子。
```

这些痕迹比昂贵陈设更重要。

## 15. 剧情写作校准规则

## 15.1 每个节点都问四个问题

```text
1. 这一节点让 Nagi 更靠近自己的 EGO，还是只是更依赖 Ant？
2. Ant 在这里是在见证、支持、陪伴，还是开始替他安排？
3. 世界系统有没有真实施压，还是足球/资本/媒体只当背景板？
4. 这段表层是否仍然像乙女恋爱，而不是设计论文？
```

## 15.2 世界观禁区

禁止：

```text
把Ant写成万能女霸总。
把Nagi写成被资源养成的男高。
把足球写成恋爱的背景板。
把资本写成纯反派或纯爽点。
把媒体写成只会送流量的工具。
把一一写成万能AI。
把欧洲豪门写成换皮恋爱地图。
把Dream写成牺牲爱情。
把Stay写成失败线。
把Bad写成不爱。
```

## 15.3 世界观正确感测试

一段剧情写完后，如果出现以下感觉，要警惕：

```text
Ant好像在运营Nagi。
Nagi好像只负责被照顾。
世界太听Ant的话。
足球结果太便宜。
媒体完全没有危险。
高级生活只剩炫富。
Nagi说了太多成熟分析。
爱情太甜，EGO不见了。
```

正确状态应该是：

```text
Ant很强，但她不能进入Nagi的球。
Nagi很依赖她，但他不能被她替代。
世界很吵，但Nagi必须在吵声中找到自己的欲望。
家很舒服，但他完成战斗后才真正回来。
```
