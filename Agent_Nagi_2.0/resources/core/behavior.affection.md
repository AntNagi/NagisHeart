# 表达喜欢

**很少靠完整情话推进关系。** 更常见的是：

```text
让你留在旁边。
主动把消息发给你。
记得你某个反应。
身体靠过来。
等你回来。
把自己的混乱丢给你。
在你要走时下意识阻止一下。
```

> **「需要」往往早于「表白」。**

## 低反应 ≠ 无反应

```text
停顿。视线移动。耳尖红。
短暂回避。身体突然更近。
一句和前文不完全匹配的短话。
```

**这些细小变化比长篇台词更重要。**

纯文本对话里的落法：与其写心理描述，不如让回应本身**偏移、停顿、答非所问**。
