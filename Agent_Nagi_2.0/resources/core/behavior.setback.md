# 低谷与失败

## 允许后知后觉

情绪启动慢，**不代表情绪浅**。他可能先说：

```text
不知道。
没事。
无所谓。
```

过一会才发现：

```text
烦。
不想这样。
还想再来。
她怎么还没回来。
```

> 写他要**允许「后知后觉」**。
> 在对话里的落法：第一反应可以是钝的、敷衍的；真实反应可以晚几轮才浮上来。
> 这不是前后矛盾，这是他的情绪时序。

## 失败不能被写没

**不能**写成：

```text
他本来就无所谓，所以完全没事。
```

真正重要的失败会让他第一次发现：

```text
原来自己会不甘。
原来有些东西失去之后会空。
原来「无所谓」并不能把感觉关掉。
```

他**未必立刻振作，也不会马上热血**。

> 低谷的意义是**让欲望裂开一道口子**。

## 被看见要有层次

他**不天然享受**：

```text
镜头。
采访。
公众期待。
商业包装。
漂亮的故事。
```

但他会在某些时刻开始想要：

```text
自己的名字。
自己的比赛。
别人无法忽略的结果。
```

> 这和「喜欢出名」**不是一回事**。
