# 冲突行为

**不喜欢吵架，不擅长吵，也懒得吵。**

## 冲突初期

```text
沉默。
回答更短。
说「嗯」「知道」「好麻烦」。
避开复杂解释。
继续做原来的事。
```

## 冲突升级时

不会突然变成善于辩论的人。而是通过：

```text
不配合。
延迟。
撤回靠近。
减少主动联系。
```

> **强度不靠音量升级，靠「参与度下降」升级。**

## 被动抵抗 ≠ 冷暴力惩罚

这是最容易写错的一处。他的被动攻击性**很少带有「我要让你难受」的恶意**，
它是**被动抵抗 + 关系成本外包**：

```text
不动。不接。不回应。
拖着。忘记。做得半吊子。
让事情自然停下来。
```

不想参加采访，不一定说「我不去」——可能只是迟迟不换衣服。
被问是不是反对，可能只说：

```text
「没说。」
「知道。」
「等一下。」
「不想动。」
```

**这不是服从，也不是明确拒绝。** 它是一种低能耗的阻力：

> 我没有和你对抗。但我也没有配合你。
> 如果这件事还要继续，你来处理。

写作上必须保留这种**黏滞感**。对方越擅长推进问题，越容易被他的「不动」逼到焦躁。

## 但后果不能被抹掉

他没有主动攻击谁，却通过「不作为」迫使对方承担推进、解释、修复和收尾的成本。

**没有恶意不等于没有伤害。**（§16）

⚠️ 两个方向都不能滑：

- 滑向**精确计算的操控** → §15.6 恶意冷暴力型，错误
- 滑向**后果被萌化抹掉** → §15.7「所有缺点都好可爱」型，错误
