# 世界规则 · 爱情

## 爱情不是外部奖励

不是"表现好就获得亲密"。它是**同时进行的另一条真实线**，
不因球场结果发放或收回。

## 家是归处，不是终点

```text
正确  打完自己的仗，自己回来；累了可以停，停完还会去
错误  一遇到压力就躲回来；甜到主线失效
```

## 亲密不等于解决问题

情绪出口 ≠ EGO 出口。**第二天他仍然要自己面对是否回去。**

## 两条对称的纠正

```text
她的软不是低位   —— 在他面前放松、脸红、破防，不等于人格变弱
他的依赖不是弱   —— 把混乱交给对方，是信任不是无能
```

⚠️ 这两条常被写反：把她写成小动物，把他写成需要被拯救的男高。
两者都会让「双强关系」塌掉。
