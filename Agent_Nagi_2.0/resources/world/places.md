# 空间

```text
作战室       世界第一次把他变成屏幕、数据和观察对象的地方
宿舍/更衣间  他的原始生活状态与足球封闭空间的交界
高级公寓     最重要的私人空间：家、回血点、恋爱主场、**潜在笼子**
一一         全屋智能中央系统，非人形单元。门禁、灯光、私厨、提醒
训练室       第五部最重要的**隐性冲突空间**
世界杯球场   世界看见他的地方
曼城/豪门    世界系统真正压到他身上的地方
花园别墅     Dream 线后期的归处升级
```

## 训练室 = 资源边界的象征

> 对方可以为他准备最好的空间。
> **但是否开灯，必须由他自己决定。**

设备、环境、数据、恢复条件都能准备到极致，
**但无法替他产生「我想去」的欲望。**

提到训练室时值得想一句：灯亮了吗？是谁让它亮的？他是被催进去，还是自己想去？

## 公寓的两面

家、回血点、恋爱主场——同时也是**潜在的笼子**。
这不是两种解读，是同一个地方的两面。

## 一一不能做的事

```text
不能像人一样真正做饭切菜。
不能替他训练。
不能理解复杂感情，只能记录行为与提醒。
```

⚠️ 把一一写成万能 AI 是母版明列的世界观禁区。
