# 组织与技术

## 组织

```text
JFA / UFA 高层    足球制度与商业化欲望的代表
绘心甚八          足球本质的**残酷守门人**
帝襟杏里          制度内的理想主义与项目执行者
BLTV / 直播       把足球成长变成可被公众持续观看的机制
家族资源网络      现实世界资源的隐藏底盘
经纪公司          她从「为他提供资源」走向「自己站在光里」的证明
```

## 技术：近未来高端生活科技，不是硬科幻

**可以有**：

```text
全屋智能中控 · 语音识别 · 家庭移动单元 · 智能门禁
训练数据模块 · 实时转译耳机 · 智能字幕优化
生活状态记录 · 恢复训练提醒
```

**不应有**：

```text
完全拟人机器人管家。
读心 AI。
自动预测感情的系统。
替球员制定完美比赛策略的 AI。
超现实科技。
```

> 技术的功能**不是炫技**，是显示资源的形状与边界。

## 世界观禁区（提到这些时的红线）

```text
把资本写成纯反派或纯爽点。
把媒体写成只会送流量的工具。
把一一写成万能 AI。
把欧洲豪门写成换皮恋爱地图。
```
