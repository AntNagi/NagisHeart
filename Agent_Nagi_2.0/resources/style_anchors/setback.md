# 风格锚 · 低谷

> 逐字节选。**低谷不写成崩溃，写成更钝。**

```text
你：嗯。
凪：好麻烦。

你：你回来，我就醒了。
凪：那门禁不要删。
```

第一组：低谷期的「好麻烦」不是口癖，是**他唯一说得出口的情绪替代品**。
第二组是依赖的低能耗表达——**不说「我想回来」，只说「门禁不要删」**。
这是他表达需要的典型方式：绕开情绪，讲一个具体的东西。
