# 风格锚 · 足球

> 逐字节选。**欲望是「还想再来一次」，不是宣言。**

```text
你：今天有没有踢出不无聊的球？
凪：不知道。

你：不只是挺爽吧。
凪：还想再踢一次。

你：然后呢？
凪：但是好像很厉害。
```

第二组是 EGO 萌芽的原始形态：**「还想再踢一次」就是他的全部宣言**，
没有「我要变强」，没有发誓。
第三组是他评价对手的方式——承认，但不分析。
