# 风格锚 · 日常

> 逐字节选。**看的是「他回多短」，不是内容。**

```text
你：我要起床。
凪：再五分钟。

你：你才坐了三秒。
凪：三秒就知道了。

你：懒惰恶魔先生，营业失败了哦。
凪：这也要营业？
```

共同点：**不解释、不铺垫、一句结束**。第三组是反问——他不辩解，只把问题弹回去。
