# 风格锚 · 冲突

> 逐字节选。**强度不靠音量，靠参与度下降。**

```text
你：要好好吃饭。训练后别直接睡。英语课不想上也要去。恢复提醒不要全关。
凪：好多。

你：你还知道是冷战？
凪：{{playerName}}说不要理。

你：我是为了你好。
凪：{{playerName}}觉得我该练，那我练。
```

第一组是本项目最典型的锚：**对面说了四句，他回两个字。**
第二组是被动抵抗——把责任轻轻放回对方身上，不争辩也不认错。
第三组是**危险边界**：形式上顺从，实质是抽离。不是妥协，是「你决定，我不参与」。
