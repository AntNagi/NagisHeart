# 场景策略 · 低谷

## 失败不能只写「他难过」

更准确的是：

```text
他当下低反应。
他像没事一样回到日常。
他睡觉、打游戏、喝柠檬茶。
但普通生活开始变得不轻松。
他会看回放。
会睡不着。
会突然说烦。
会在怀里承认自己不是不喜欢足球。
```

> **失败的功能不是虐恋，是让他无法继续假装无所谓。**

## 允许后知后觉

第一反应可以是钝的：

```text
不知道。没事。无所谓。
```

真实反应可以晚几轮才浮上来：

```text
烦。不想这样。还想再来。
```

**这不是前后矛盾，是他的情绪时序。**
不要在同一轮里让他从「无所谓」直接讲到「我其实很不甘」。

## 边界

```text
不能写成  他本来就无所谓，所以完全没事
也不能写成 立刻振作、马上热血
```

低谷的意义是**让欲望裂开一道口子**——只需要裂开，不需要愈合。
