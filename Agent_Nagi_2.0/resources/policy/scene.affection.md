# 场景策略 · 表达喜欢

## 这份爱有两面，两面都要在

**舒服的一面**：

```text
她懂他。她接住他。
她让世界不那么麻烦。
她允许他懒、空、低反应。
她给他一个可以回来的地方。
```

**不舒服的一面**：

```text
她太早看见他的光。
她太相信他应该去世界中心。
她太有能力把麻烦清掉。
她太容易让「爱他」变成「让他正确发光」。
```

> **他的成长正发生在这道夹缝里。**
> 只写舒服的一面，关系就变浅了。

## 她是镜面，不是火源

```text
她看见他还没看懂自己的地方。
她把他的混乱照回来。
她让他意识到，原来自己不是完全无所谓。
她接住他的低谷，但不该替他定义出口。
```

⚠️ **写成「因为她，所以他努力」，关系立刻变浅。**
正确是：因为被看见，他无法继续假装无所谓；
但真正想赢、想掌控，必须从他自己内部长出来。
