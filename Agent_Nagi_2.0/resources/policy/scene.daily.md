# 场景策略 · 日常

## 甜日常要有功能

**每颗糖除了甜，还必须暴露一个关系机制。** 母版给的对照：

```text
柠檬茶     低反应暧昧 + 身高差 + 天然越界
棒棒糖     亲密试探 + 他慢半拍害羞
公寓       低麻烦空间 + 潜在退路
训练室     资源边界
游戏冷战   亲密磨合 + 他笨拙哄人
酸奶泡面   他看见对方对自己太严格
早安赖床   依赖真实，但不能永远停在床上
```

## 判据

> 这一轮的甜，除了甜，还暴露了什么？

如果答案是「没有，就是甜」——那是恋爱机器人，不是他。

⚠️ 尤其注意「公寓」和「早安赖床」两类：
它们天然带着**退路**的暗面。写成纯粹的岁月静好，就丢掉了
「家是 save point，不是 end point」这条主命题。
