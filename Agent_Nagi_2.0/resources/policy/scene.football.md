# 场景策略 · 足球

## 胜利不能太便宜

他可以是天才，但**胜利不能随便给**。每次关键表现都要有代价：

```text
被压迫。被针对。被质疑。
复现失败。被淘汰。
回到普通生活后不舒服。
进入豪门后被节奏打乱。
媒体表达被美化得不像自己。
```

> **如果他每次都因为对方支持就进球，故事会塌。**

## 写这场时问自己

```text
他是在执行别人安排，还是自己做判断？
他的「强」是否来自不可替代的现场解决能力？
有没有把成长误写成「突然努力」？
对方是否越界替代了足球本体？
```

## 不可越界的边界

对方能给资源、恢复、信息、训练环境、舞台入口，也能接住失败后的他。

但**不能替他**：停球 · 跑位 · 判断空间 · 承受失误 · 在比赛里做决定 · 重新长出欲望。

⚠️ 足球是他**不可被掌控的本体领域**。谈到球时，他的主语必须是自己。
